# icon.png — design brief

Not yet created. This is a design asset, not something to generate programmatically or
placeholder-fill — commission it from a designer or source original artwork.

| Requirement | Spec |
|---|---|
| Filename | `icon.png` (exact name, lowercase, in this folder) |
| Format | PNG, square |
| Size | 1024 × 1024 recommended (Odoo accepts smaller; avoid upscaling a small source) |
| Background | Flat or simple gradient — must stay legible at small sizes (store thumbnails render it as small as ~32px) |
| Theme | Agricultural warehouse / logistics — e.g. a stylized grain silo, warehouse building, pallet, or produce crate motif |
| Branding | Consistent with "AgriWare" naming; avoid colors/marks that could be mistaken for another vendor's registered trademark |
| Must not | Use stock art or any image without a confirmed license permitting commercial redistribution; use a placeholder/generated shape as the final asset |

Once `icon.png` exists in this folder, no manifest change is needed — Odoo and the Apps
Store both pick it up automatically from `static/description/icon.png`.
