AgriWare Connector

Connect Odoo 19 with AgriWare, an open-source warehouse management system for agribusinesses.

What it does

AgriWare Connector exposes a REST API on top of Odoo's Inventory app so an external AgriWare warehouse management system can read product, warehouse, and stock data, and create and validate incoming receipts and outgoing dispatches, without a human re-keying anything into Odoo. AgriWare remains a standalone application; this module is the bridge between the two systems.

Key features

  • REST API for products, warehouses, and on-hand inventory
  • Create and validate stock receipts (incoming deliveries)
  • Create and validate stock dispatches (outgoing deliveries)
  • Odoo API key authentication (Bearer token)
  • Dedicated role-based access group for external integrations
  • Concurrency-safe duplicate protection on receipt/dispatch creation
